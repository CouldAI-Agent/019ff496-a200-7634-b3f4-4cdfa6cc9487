# Bipin Kirana Store

A modern, premium, responsive e-commerce supermarket app built for Bipin Kirana Store (Gautam Mohalla, Sohagpur, Shahdol, Madhya Pradesh). Features a Blinkit/Zepto inspired UI with categories, product grids, and a shopping cart experience.

## Features
- Clean, premium UI
- Light and Dark modes
- Product and Category browsing
- Shopping Cart state management

## Tech Stack
- Flutter
- Provider (State Management)
- Google Fonts

## Setup
1. Run `flutter pub get`
2. Run `flutter run`
